# 天马座夹爪快换 · V0.4

公开评审页面：两块一体刚性 PCB、安装预留与 STEP 拆换动画。

- Board A：Ø60 异形固定侧主板，MCU、电源、CAN、H1/H2 和焊接弹簧针集成。
- Board B：44×36 水平板舌，触点、双 ADS1220 与接口集成。
- H1/H2：TMAG5173-Q1；POGO：P70-1000045R 结构初样候选。
- 按固定库位选择工具，锁紧后工具上电。
- 固定侧电子腔、上盖及板舌支承需要改型；图和动画为设计预留，原 STEP 未修改，未完成 PCB 布线与强度验收。
