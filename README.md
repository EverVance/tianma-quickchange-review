# 天马座夹爪快换 · V0.5

公开评审页面：固定侧独立保护壳、40×10 mm 夹爪侧板、硬件框图与拆换动画。

- Board A：Ø60 一体主板，霍尔与弹簧针直接焊板，固定侧保留可拆保护底盖，分离后仍覆盖电路。
- Board B：40×10 mm 一体板，正面触点，背面双 ADS1220 与滤波，接口重新布局。
- 固定件上连接面增加2 mm，保留原定位凸台与凹槽。
- 朝磁铁的A板面距离4.8 mm；霍尔敏感点约4.13 mm为未扣焊层名义值，非测距精度。
- 按固定库位选择工具，退出夹座并确认锁止后上电。
- 结构、板框和器件占位为评审候选，原STEP与PCB工程未修改；PCB走线、装配公差、磁场标定及壳体强度未验收。

入口`index.html`；动画`motion.html`；可编辑框图`hardware.drawio`。
